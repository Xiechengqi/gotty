## 整体 Review 发现及修复

1. **注册握手数据竞争**：SessionManager 关闭 `client.ready` 后又赋 nil，与请求处理器等待该字段并发。移除字段重赋值，保持 channel 引用不可变，以关闭操作发布 replay 初始化结果。
2. **启动失败的 context 泄漏**：`Server.Run` 的部分错误返回路径未取消派生 context，增加 `defer cancel()`。
3. **移动端容器实际尺寸错误**：本地全屏 `min-height` 会覆盖按键栏设置的缩小高度。软键盘开启时临时覆盖最小高度及 box sizing，关闭和销毁时恢复；增加真实浏览器容器边界断言。
4. **取消后的异步回调**：发送取消后 promise 仍可能执行 close/onFinish；接收取消后仍可能保存文件。增加完成/取消检查，清理接收进度定时器，防止重复发送和空文件列表启动传输。
5. **本地权限和 API 差异**：移动按键使用包含只读分享状态的有效写权限；主题选择器扩展现有 options 接口，保留本地控制项隐藏行为。
6. **尺寸与生命周期冲突**：移动视口接管时停用原有视口 resize 路径，复用 requestAnimationFrame 调度；清理延迟触摸初始化、视口监听及长按定时器；尺寸变化时保留滚动位置。
7. **产物和许可遗漏**：构建依赖包含配置及锁文件，明确生成全部 JS 相关产物；启用许可清单并关闭模块合并以保留 xterm 条目；本地构建助手执行独立类型检查。
8. **多架构嵌入及发布门槛**：统一 Linux 构建脚本按目标准备客户端，退出后恢复本地嵌入文件；发布等待验证，缺失产物时失败，串行化同一分支的 latest 发布。

Review 后未发现尚未修复的阻断性代码问题。此结论限于本次改动和下列实际验证范围。
